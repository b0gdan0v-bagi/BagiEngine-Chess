# Chess rules (src/Chess/Game)

Part of the Chess documentation, split out of the root `CLAUDE.md` (which holds the overview, the control API, the rules and the map of these files) so that a session loads it only when it works here. A section named in quotes may be in a sibling file: the scene and the UI in `src/Chess/Components/CLAUDE.md`, the opponent in `src/Chess/Engine/CLAUDE.md`, the rules in `src/Chess/Game/CLAUDE.md`, the tests in `tests/CLAUDE.md`.

## Files

```
├── Game/                     plain C++ rules, no scene or renderer
│   ├── ChessTypes.h          Square (file, rank), PieceType, PieceColor, Piece
│   ├── Bitboard.h            Bitboard (a1 = bit 0), masks, shifts, PopCount / Lsb / PopLsb
│   ├── Move.h                Move: 16 bits (from, to, promotion piece, kind), ToUci()
│   ├── Attacks.*             AttackTables (SingletonAtomic): knight / king / pawn tables, rook and bishop magic bitboards, Between / Line, Zobrist keys
│   ├── Position.*            pieces as bitboards + 64-cell array, side to move, castling rights, en passant, clocks, Zobrist key; FEN, DoMove / UndoMove, IsLegal, checkers and pins
│   ├── MoveGenerator.*       GenerateLegal(position) -> MoveList; ParseUci(position, text)
│   ├── MoveNotation.*        `SanOf(before, move)`: the standard algebraic notation of a legal move, pure ("e4", "Nf3", "exd5" also for en passant, "O-O" / "O-O-O", "e8=Q"); English piece letters; a piece gets its file, else its rank, else both when another piece of the same type can **legally** go to the same target (a pinned piece does not count); "+" for check and "#" for mate, nothing for a stalemate or a draw; `before` is not changed; the overload `SanOf(before, move, legal)` takes the legal moves of `before` that a caller has already (the two-argument one generates them), the check suffix generates the position after the move only when the move gives check; `ParseSan(position, san)` (and an overload with the legal moves) is the inverse, for text from outside (the `pgn` of the opening table): the one **legal** move the text names, else nothing (no match, ambiguous, garbage; it never asserts), a trailing `+#!?` ignored, `0-0` accepted, a king step `Kg1` never takes the castling move
│   ├── MoveList.*            `BuildMoveList(startFen, moves)` -> `MoveListRow`s (`number`, `white` and `black` as `MoveListEntry{san, ply}`), pure: the rows of the move list as a score sheet, replayed from the start FEN with `SanOf` on the position before each move (the legal moves of each position are generated once, for the legality check and the text); `ply` is the index in `ChessGameModel::GetMoves()` (-1 and an empty `san` for a place with no move); the first number is the fullmove number of the start position, a game that began with Black to move has a first row with no White move, the last row may lack Black; a broken FEN gives no rows and a move that is not legal in its turn ends the list there
│   ├── GameStatus.*          EvaluateStatus(position): Ongoing, Checkmate, Stalemate, DrawInsufficientMaterial, DrawThreefold, DrawFiftyMoves (the position's own: it never returns `Resigned` / `DrawAgreed`, which only the model sets); `kFiftyMovePlies` (100), the one threshold of the 50-move draw, which `Engine/Search.cpp` uses too
│   ├── StatusText.*          the words of the HUD: Turn(model, opponentThinking = false) ("White to move", "White wins", "Draw"; "Computer is thinking" while the game is on and the program searches) and Status(model) ("", "Check", "Checkmate", "Draw: threefold repetition", "White resigned", "Draw agreed", ...; `DrawDeclined()`: "Draw declined", the line of a refused offer, published by the HUD; `ResignQuestion()` / `DrawQuestion()`: the questions of the menu section "Game"; while viewing `Viewing(model)`: "At move 12 - tap board", the score-sheet number of the last shown move, or "At the start - tap board", short enough for the narrowest Status)
│   ├── BoardOrientation.h    where a square is drawn, pure and header only: `BoardCell` (column, rowFromTop), `BottomColor(programPlays)` (Black exactly when the program plays White, else White), `CellOf(square, bottom)` and its inverse `SquareAt(column, rowFromTop, bottom)` (nothing outside 0..7); Black at the bottom is the White grid turned by 180 degrees
│   ├── BoardCoordinates.h    what is written at the edge of a drawn cell, pure and header only, built on `SquareAt` / `CellOf` (no second copy of the orientation maths): `FileLabel(column, bottom)` (the letter of the file in the bottom-row cell of a column; empty outside 0..7), `RankLabel(rowFromTop, bottom)` (the number of the rank in the left-column cell of a row), `IsLightSquare(file, rank)` (the one rule of the checkered base, which `ChessBoardComponent` paints with) and `IsLightCell(column, rowFromTop)`; `kLabelColumn` = 0 and `kLabelRow` = 7 are the edge cells; White at the bottom reads a..h and 8..1, Black at the bottom h..a and 1..8
│   ├── PromotionChoices.*    the four pieces a pawn can become, pure: PromotionPieces() (queen, rook, bishop, knight), PromotionId(type) ("queen", "rook", "bishop", "knight"), PromotionLabel(type) ("Queen", ...), FindPromotion(id) (exact, lower case); one table, which the promotion panel is held to
│   ├── MenuSections.*        the sections of the menu, pure: `MenuSections()` (the order of the buttons of the list) and `FindMenuSection(id)` (exact, lower case) -> `MenuSection{id, node, label}` ("opponent", "OpponentPanel", "Opponent"; "moves", "MovesSection", "Moves"; "game", "GameSection", "Resign / Draw"; "sound", "SoundPanel", "Sound"); a section the build has no panel for has no row, and a later feature adds its row here
│   ├── CapturedMaterial.*    what a position says about the material, pure (`Game/` must not know `Engine/`, so the points are not `Evaluation.*`'s centipawns): `MaterialPoints(type)` (pawn 1, knight 3, bishop 3, rook 5, queen 9, king and none 0), `CapturableTypes()` (queen, rook, bishop, knight, pawn: the order of the rows of a display), `CapturedId(type)` ("queen" ... "pawn", lower case) and `FindCaptured(id)` (exact), `SummarizeMaterial(position)` -> `MaterialSummary` (`GetMissing(color, type)`: the pieces of that color that are gone = the start set minus the board, `GetPoints(color)`: the points it has on the board, `GetBalance()`: white minus black) and `BalanceText(pointsAhead)` ("+N" for 1..99, "+99" above, "" for no lead). **Position-only:** a piece beyond the starting set is a promoted pawn (it counts in the points and is not a missing pawn: pawns missing = 8 - pawns - extras), a pawn that promoted into a missing piece shows as a pawn gone, and a promoted piece that is taken later shows as a missing pawn, because the position cannot tell them apart; no count is negative, also for a position the rules cannot reach
│   ├── MaterialLayout.h      where the lists of captured pieces lie, pure and header only: the box of the two lists in the left margin of the default view (`kMaterialListLeft` 8, `kMaterialListTop` 84, `kMaterialListRight` 72, `kMaterialListBottom` 716) and the `kMaterialPortrait*` box of the two rows of the Portrait view, `kMaterialGroupCount` (2), `kMaterialRowsPerGroup` (5) and `kMaterialSetCount` (the margin set and the one in the move panel's bands), and `MaterialListFits(safeLeft, safeTop, safeRight, safeBottom, MaterialView)`: whether the whole box of the view lies inside the safe area (the edge itself counts as inside), which `ChessMaterialComponent` asks to show or hide the rows; `ChessUiTest` holds the lists of the scene to these numbers
│   ├── MovePanel.*           the pure side of the move panel (the node `MovePanel`): its box in the Wide view (`kMovePanel*`, 760..1080 x 80..720) and in the Tall view (`kMovePanelTall*`, 40..680 x 840..1128) and `MovePanelFits(safeLeft, safeTop, safeRight, safeBottom, MovePanelView = Wide)` (the box of that view inside the safe area, the edge counts as inside; the panel is hidden otherwise, and `ChessMaterialComponent` asks the Wide box to put the material in the panel), and `BuildMovePanelRows(rows, currentPly, visibleRows = kMovePanelRows)` -> **always exactly `visibleRows`** `MovePanelRow`s (`number` "<n>.", `white` / `black` as `MovePanelCell{text, current, ply}`, `shown`): the **page** of the row that holds `currentPly`, pages of `visibleRows` counted from the end of the list (the first page holds what is left), so viewing a row of the window keeps the window (-1: the start position, the first page; a ply no row has: the last page, nothing current), the entries after it empty and not shown, an absent White move `...` and never current; `ParseMoveListPress(value)` (`white<i>`, `black<i>`, `back`, `forward`, `latest`) and `ShownMovesAfter(press, rows, shownMoves, gameMoves)`: the argument of `ChessGameModel::ShowMoves` for a press of the list (nothing for a cell with no move)
│   ├── Premove.*             `Premove{from, to}` and `PremoveBoard` (the position with the queued premoves lifted over it), pure: `Targets(from, color)` is the geometry of a premove, which is **not** the rules' (the opponent's answer is not known yet): own pieces block and an opponent's never does, check and pins are ignored, a pawn's diagonals are targets with or without a piece, no castling; `Apply` lifts a piece and a pawn that reaches the last rank becomes a queen (**a premoved promotion always plays as a queen**)
│   ├── GameEnding.h          `ResigningColor(sideToMove, programPlays, twoPrograms)`, pure and header only: the color the person resigns for (against the program the person's color, whoever is to move; with two people the side to move; nobody with two programs)
│   ├── TakeBack.h            `TakeBackPlies(movesPlayed, sideToMove, programPlays)`, pure: the argument of `ChessGameModel::TakeBack` for one takeback of the person (the button and `set_state {"takeBack"}`), so that the person is on the move again; `programPlays` is `OpponentController::GetPlays()`: nobody or both programs 1, the person to move against the program 2 (its answer and the person's move; 0 when the only move is the program's), the program to move 1 (the search in flight goes stale); 0 before the first move
│   └── ChessGameModel.*      selected square, legal moves of it, status, move history, version, piece handles, the pending promotion; OnSquareClicked drives select / move (a click on a promotion target moves nothing: it leaves the promotion pending, HasPendingPromotion() / GetPromotionTarget(), and any other click drops it), ChoosePromotion(PieceType) plays the pending one (`IllegalMove` when none is pending or the piece is not one of the four), CancelPromotion() drops it and keeps the selection, TryMove(Move) is the one place a move is applied (a promotion by UCI or the program names its piece), SetPosition(Position) starts a game from a FEN, `Resign(color)` / `AgreeDraw()` end the game (`Resigned` with `GetResigned()` and the other color as `GetWinner()`, `DrawAgreed` with no winner; `GameOver` on a finished game; one version step, selection, pending promotion, premoves and view dropped; `IsGameOver()` stays `_status != Ongoing`, so every guard already stops), they end with `Reset`, `SetPosition` and a `TakeBack` that takes a move (the status is the position's again), a `TakeBack` that takes nothing keeps a resigned game resigned, ClearSelection() drops a half-made move and a pending promotion for an owner that takes the turn; a pending promotion is not a change of the game, so the version does not move; `TakeBack(plies = 1)` takes the last `plies` moves back in one step (all there are when fewer; returns how many, 0 changes nothing and keeps the version): the position goes back by `Position::UndoMove` (its history of repetitions stays right), the status is worked out again (a finished game is on again), selection and a pending promotion are dropped, the version grows **once**, and the piece handles are rebuilt by replay (dealt to the position the game began from, then `RelocatePieces` for each kept move, so a captured piece is back and a promoted one is a pawn); `GetStartFen()` does not change, so a game from `SetPosition` goes back to that position and no further; **the premove queue** (`GetPremoves()`, `GetPremoveColor()`) is no change of the game, so no queue call moves the version (the move `PlayPremove()` plays does): `OnPremoveClicked(premover, square)` is the click flow on the premove board (select, queue, reselect, **any other click drops the whole queue**; the selection is the ordinary one, so `OnDraw` shows it), `PlayPremove()` plays the front through the same body as `TryMove` and drops the **whole** queue when the front is no longer legal, `ClearPremoves()`; the queue also goes with `Reset`, `SetPosition`, `TakeBack`, the end of the game and a public `TryMove` of the premoving color, and `ClearSelection()` keeps it; **the seed** (`GetSeed()`, `SetSeed()`, `SetSeedSource()`): 0 = no variety (a bare model, so every test model), `Reset()` and a `TakeBack()` that takes something draw a non-zero one from the source when there is one (in their version step), `SetPosition()` keeps it, `SetSeed()` moves the version only when the value changes; **viewing** (`ShowMoves(count)`, `EndViewing()`, `IsViewing()`, `GetShownMoveCount()`, `GetShownPosition()`, `GetShownSquareOf/PieceOf`): the board shows the position after the first `count` moves (0 is the start, `count` >= the moves is the game itself) through a copy of the position and a second set of handles, while the game, its handles and **its version** stay (a view is like a selection: a search in flight stays valid); starting it drops the selection and a pending promotion, the premove queue stays; every change of the game ends it (a move, `Reset`, `SetPosition`, `TakeBack`), and so does `OnSquareClicked` / `OnPremoveClicked`, which then do nothing else
```
