# Chess config

The scene (`SceneConfig.xml`: the board, the pieces, the HUD, the menu list, the opponent and promotion panels, the coordinates, the captured material) is described in `src/Chess/Components/CLAUDE.md`; read it before changing the scene. The settings files (`ChessSettings.xml`, the git-ignored `ChessSettings.local.xml`) are in `src/Chess/Engine/CLAUDE.md`, "The settings file".

**In the browser** the engine's web overlay (`engine/web/config/`: `ApplicationConfig.xml`, `LoggerConfig.xml`, `SDLWindowConfig.xml`) replaces a file of the same name **whole**; Chess has no web config of its own. Its `ApplicationConfig.xml` must stay the overlay's apart from `renderer` (`ChessWebConfigTest` fails otherwise): an attribute added here, such as a title or a `mode`, would be dropped in the browser. Do not give `config/` a file named like an overlay file. The files of `config/` and `assets/` that stay out of the web package (`*.md` such as this one, `*.local.xml`, `imgui.ini`, `.DS_Store`, `*.py`, `__pycache__`) are in `cmake/ChessWeb.cmake`; the five files that go in (the list is in `tests/check_web_package.cmake`) are in root `CLAUDE.md`, "The web build"; `BagiChessWebPackageCheck` fails when a new file appears there.
